## conclusion

- especially cial 有直接读成“克”的
- comfortable 重音不对（重音放在ta上了）
- Treasure hunt 中 treasure 的发音，sure 发成了“洗儿”
- decorate 重音不对
- describe scribe的 i 的发音不对，有些发成了“衣”
- pleasure 其中 sure 和 treasure犯了同样问题。
- appearance 其中 pear 
- pleasant 其中 s 发成了 “丝”
- straightforward 有不太敢读的
- character chara发成“茶...”
- instruction 重音位置不对（重音发在 in 上了），也有把 stru 的 u 读成 “污”
- photography 重音位置不对（重音发在 pho 上了），发音不对。
