### 一、与面积综合

1.三角形常见的求面积方法：

$S = \sqrt{p(p-a)(p-b)(p-c)}$

$S = \frac{1}{2} ab\cdot \sin C$

$S = \frac{1}{2} a \cdot h$

$\frac{a}{\sin A} = \frac{b}{\sin B} =\frac{c}{\sin C}= \frac{abc}{2S_{\Delta ABC}}$

$S = \frac{1}{2} |x_1 y_2 - x_2 y_1|$

铅锤高、水平宽、围框法

2.多边形常见的求面积方法：

- 各自对应的面积公式
- **分割成三角形**

### 三、折叠问题

几种对称问题的解法：

1. 点关于线对称：已知\(P_1(x_1, y_1)\)与\(P_2(x_2,y_2)\)关于\(l:Ax+By+C=0\)对称，则满足方程组：

    \[
    \left\{\begin{matrix}
    \frac{x_1+x_2}{2}A + \frac{y_1+y_2}{2}B + C = 0 \\
    \frac{y_2-y_1}{x_2-x_1} \cdot (-\frac{A}{B}) = -1(B\ne 0)或y_1=y_2(B = 0)
    \end{matrix}\right.
    \]

2. 点关于点对称：已知\(P_1(x_1, y_1)\)与\(P_2(x_2,y_2)\)关于点\(C(a, b)\)对称，则有：

    \[
    \left\{\begin{matrix}
    \frac{x_1+x_2}{2} = a \\
    \frac{y_1+y_2}{2} = b
    \end{matrix}\right.
    \]

3. 直线关于点对称：（相关点法）若原直线为\(l_1\)，有一点为对称中心\(T(x_0, y_0)\)，记\(l_1\)关于\(T\)点的对称直线为\(l_2\)。那么我们假设\(l_2\)上有一点\(K(x,y)\)，则有\(K\)关于\(T\)的对称点一定在\(l_1\)上，即满足\(l_1\)的方程。

4. 直线关于直线对称：（到角公式）

\[
\frac{k_2 - k}{1+k_2\cdot k} = \frac{k - k_1}{1+k_1\cdot k} 
\]

接着就转化成了**点关于直线对称**的问题。
